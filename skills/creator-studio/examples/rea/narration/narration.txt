# 01 开场
大家好，我是知识猫。
你有没有过这种时候：在别人的软件里看到一个特别好用的功能，很想知道它是怎么做出来的，可手里根本没有源代码。
今天聊的这个开源项目，就是专门干这件事的。
它叫 REA，全称 Reverse Engineer Anything，逆向一切。

# 02 热度
它今年四月才开源。
半年时间，拿到了十四万六千多颗星，三万三千多次复刻。
十月十一号刚发布六点四版本，几乎每天都有新提交，开源协议是 MIT。

# 03 它是什么
一句话概括：REA 是一个专为 AI 智能体打造的逆向工程 MCP 服务器。
你不用自己去啃汇编，而是直接问你的智能体。
比如：帮我搞清楚某个笔记软件的搜索是怎么实现的，附上证据，再在我的项目里做一个类似的。
智能体通过 MCP 调用 REA，去检查目标、追踪相关代码。
REA 把发现连同证据一起交回来，智能体再基于这些去解释、去实现、去测试。
同一套能力，在终端里也能直接用。

# 04 能分析什么
它覆盖的范围有点夸张。
原生二进制，可以接 Hopper、Ghidra 或者 IDA，拿到伪代码、汇编、字符串和调用关系。
JavaScript 和 Electron 应用，能还原模块、导入关系和进程间通信。
还有网站、抓包文件、点 NET 程序集、安卓安装包和真机、Go、WebAssembly、以太坊字节码、固件，甚至 Flutter 应用。
而静态的 JavaScript 和点 NET 分析，连原生分析引擎都不需要装。

# 05 实测
光说不练没意思，我们直接拿我自己开刀。
我，知识猫，就是一个用 JavaScript 画出来的网页角色。
在终端里敲一行命令，让 REA 分析我的原型目录。
六秒钟，它读完了五个相关文件，解析了两个 JavaScript 模块，遍历了一万四千多个语法树节点。
它认出了我的动画引擎和绘制模块，也找到了两个页面入口。
最让我喜欢的是最后这一段：它会主动告诉你，局限在哪里。
比如代码只是被当作静态文本解析，从来没有执行过；静态的导入关系，也不能证明运行时真的会走到。
结论、证据和边界放在一起，这对智能体特别重要，它就不会把猜测当成事实。

# 06 官方案例
官方还放了几个相当硬核的案例。
老游戏 DX-Ball：REA 顺着一次声音调用，找到计算声像位置的函数，把残缺的伪代码还原成 C 代码。
还原结果通过了三千两百多个原始 x86 测试用例，六十三个编译后的字节完全一致。
还有 Notion：从页面里的剪贴板接口出发，一路追到预加载脚本、进程间通信，再到主进程。
以及一款 PC-98 平台的原版游戏，恢复了十六位 DOS 时代的子弹环计算。

# 07 上手
上手很简单。
装好 Node 二十二以上的版本，运行 npx rea-agents setup。
选择你用的智能体，Claude Code、Codex、Cursor、Gemini CLI 都支持，确认改动，再重启一下就可以了。
分析全部在本地运行，不会上传你的程序。

# 08 提醒与结尾
最后提醒两句。
逆向工具是把双刃剑，只分析你有权分析的软件。
运行时捕获会真的执行目标程序，要留意它的影响；IDA、Hopper 这类商业工具，也需要合法授权。
