# 三种形式

| 形式 | 主画面 | 时间轴从哪来 | 场景是什么 | 默认主题 / 主讲版式 / 转场 |
|---|---|---|---|---|
| `explainer` 讲解 | 全屏动效场景 | 稿子先行（`tts.py`） | 不透明的全屏场景（主题底色），一句话一个视觉焦点 | lab · `side` · push |
| `tutorial` 教程 | 录屏（主题窗口框或全幅） | 素材先行（`ingest.py`）；也可事后配音 | 透明叠加层：标注、步骤条、按键、章节卡 | night · `pip` · fade |
| `talk` 口播 | 主播画面：摄像头 / 数字人 / stage 模式的 IP 角色 | 真人素材先行（`ingest.py`）；IP 和数字人稿子先行（`tts.py` + `tighten.py`） | 透明叠加层：钩子大字、双层花字、关键词贴纸、下三分之一、偶尔一张全屏卡 | lab · `full` + 跳推 · fade |

三种形式可以在一期里混用：教程的开场和结尾用 `full`（真人出镜），中间 `pip`；讲解里插一段录屏，就给那一段写 `screen.json` 的 `segments`。

## 讲解（explainer）

结构参照 `examples/rea/`：痛点开场 → 热度 → 它是什么 → 能做什么 → 实测 → 案例 → 上手 → 提醒收尾。场景型见 `scene-kit.md`。

- 每个场景以主题底色铺满（`video.json.ground` 可逐场指定主题命名色，如 `"03": "blue"`；`"invert"` 反白做金句 / 收尾）。
- 主讲是 mascot 时站在 `ip.json.zones`（host / side / peek / center）；是 camera / avatar 时默认 `side`（右侧 34% 栏），场景内容放左侧 0–1180px。

## 教程（tutorial）

录屏是主角，叠加层只做三件事：**指出看哪里**（screen.json 的 focus 推近 + marks 标注）、**告诉进度**（步骤条 `.step`、章节卡）、**补充看不见的**（按键 `.keycap`、命令、结论贴纸）。

- 节奏：一步操作一次推近；推近停 2–4 秒再拉回全屏；同时最多一个标注。
- 场景默认透明（`ground: none`），章节卡是一个铺满的反白块（`class="tone-invert"` 的全屏 div），1–1.5 秒后淡出。
- 等安装 / 等加载的空档由 ingest 自动加速并出"⏩ N×"角标，不要在叠加层里再解释。
- 主讲版式：开场 `full`（自我介绍）→ 操作段 `pip` → 讲原理时 `side` → 结尾 `full`。纯配音教程用 mascot 小窗探头或 `none`。

## 口播（talk）

人像是主角，叠加层少而准：一句话里只挑一个值得被看见的词。

- 下三分之一（`.lower-third`）只在开场出现一次：名字 + 一句身份。
- 关键词贴纸（`.kw`）放在人像两侧的空白里，不压脸；`.note` 手写批注适合 paper 主题。
- 需要展示数据 / 对比 / 清单时，插一张全屏卡（场景里一个铺满的 `.card` 或反白块），说完就撤。
- 竖版（抖音）自动从横版生成：上标题条、中间是横版画面、下面是人像卡片和字幕，见 `platforms.md`。

## 口播节奏（口播必读，教程和讲解也适用）

提炼自高留存口播剪辑的做法，数字是起点，以试看为准：

- **钩子**：第一帧就有大字（`.hua.xl`，全片最强的那句：痛点、结果前置、反常识、提问、数字），0.5 秒内出现；不要寒暄开场，"大家好"放在钩子后面。
- **视觉节拍**：每 2–4 秒一次变化，超过 6 秒没变化就补一个；每 15–20 秒一次大变化（换版式、章节闪白、全屏卡）。手段按成本从低到高：跳推（track 的 `zoom` + `cut`）→ 花字 → 版式切换（全屏 ↔ 小窗 ↔ 侧栏）→ 录屏 / 示意图 → 全屏卡。**同一手段不连着用三次。**
- **双层花字**（`.hua`）：上面一行语境（`.ctx`），下面关键词（`.key`，约 1.6 倍、主题花字色），关键词卡在它的**起音**上（时间查 `narration/words.json`），用 `slam()` 撞进来；每 8–12 秒最多一个，数字连单位一起出；说完用 `out()` 撤掉。否定 / 纠错用 `strike()` 划掉或 `shake()`。
- **字幕**：口播默认无底板白字黑描边（`captionStyle.look: "bare"`），每屏 ≤ 14 字；要底板写 `"look": "card"`。
- **章节**：口播默认顶部有章节胶囊（`"chapters": false` 关掉），换章用 `"transitions": {"03": "flash"}` 闪白。
- **声音**：旁白跑一遍 `tighten.py` 压停顿；音效自动按动效配（撞字 = 低频一下、弹出 = 啵、滑入和换场 = 嗖），同一拍只留一个、3 秒内最多两个，`"sfx": false` 关掉，`"sfx": {"volume": 0.7}` 调小；配乐写 `"bgm": {"src": "assets/bgm.mp3", "volume": 0.12}`（自备无人声纯音乐）。
- **结尾**：停在信息或情绪的高点，有原话号召才做号召贴纸；不加"谢谢观看"。

## 时间写法（三种形式通用）

所有动效写 `c(<旁白绝对时间>)`；时间来自 `narration/scenes.json` 每句的 `t`（素材先行时就是剪完以后的时间，看 `narration/transcript.txt`）。动作切在句首前约 0.2 秒。
